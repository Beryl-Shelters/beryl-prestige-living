# Auth typography

The auth UI uses the archived project's **Plus Jakarta Sans** variable font
(normal, weights 200–800). It is served locally with Next's font loader.

The Latin WOFF2 was reused from the existing branding asset:
`beryl-prestige-living-pre-rebuild-apps/web/.next/static/media/fba5a26ea33df6a3-s.p.18rizl4rsrl42.woff2`.
Its family, weight range and Latin subset were verified against the archive's
`[next]_internal_font_google_plus_jakarta_sans_6cbc0d5f_module_css_1igg3k2._.single.css`.
No archived components, authentication logic, or configuration were copied.
