# Beryl Shelter Nigeria Limited

Official monorepo for the Beryl Shelter Nigeria Limited platform, containing the website, mobile application, backend API, shared packages, and project documentation.

Use **Beryl Shelter** as the compact display brand in navigation, buttons, short headings, and space-constrained app metadata. Use **Beryl Shelter Nigeria Limited** in full product, legal, email-footer, and other formal customer-facing contexts.

## Public URL configuration

The following canonical domains are provisional until product ownership is confirmed. Configure them through environment variables rather than hard-coding them in web, mobile, admin, or API applications.

| Environment variable | Provisional value |
|---|---|
| `PUBLIC_WEB_URL` | `https://berylshelter.com` |
| `API_PUBLIC_URL` | `https://api.berylshelter.com` |
| `ADMIN_WEB_URL` | `https://admin.berylshelter.com` |

Future web and mobile app metadata should use **Beryl Shelter** for compact app labels and **Beryl Shelter Nigeria Limited** where the full legal product name fits.
